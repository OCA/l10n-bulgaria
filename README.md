## Въведение

Това хранилище съдържа модули за българската локализация на Odoo, разработени от OCA (Odoo Community Association). Модулите осигуряват съответствие с българското законодателство в областта на счетоводството, фискализацията и данъчното отчитане.

## Чек лист с изисквания съгласно българското законодателство

### 1. Счетоводна отчетност (Закон за счетоводството, НСС)

- [ ] **Сметкоплан и счетоводни регистри**
  - [ ] Индивидуален сметкоплан съгласно НСС с минимум 3 нива на аналитичност
  - [ ] Автоматично генериране на счетоводни записи съгласно счетоводната политика
  - [ ] Хронологичен регистър на счетоводните записи
  - [ ] Главна книга за синтетично и аналитично отчитане
  - [ ] Оборотни ведомости по синтетични и аналитични сметки

- [ ] **Годишно финансово отчитане**
  - [ ] Баланс (според категорията на предприятието - микро, малко, средно, голямо)
  - [ ] Отчет за приходите и разходите (едностранен и двустранен)
  - [ ] Отчет за собствения капитал
  - [ ] Отчет за паричните потоци (пряк и косвен метод)
  - [ ] Приложение/бележки към ГФО
  - [ ] Справка за нетекущите активи
  - [ ] Справка за вземанията, задълженията и провизиите
  - [ ] Справка за ценните книжа
  - [ ] Справка за участията

- [ ] **Дълготрайни активи**
  - [ ] Счетоводни амортизации съгласно амортизационната политика
  - [ ] Амортизационен план
  - [ ] Инвентарна книга на ДМА/ДНМА
  - [ ] Преоценки на активи

- [ ] **Материални запаси**
  - [ ] Методи за оценка (FIFO, средно-претеглена и др.)
  - [ ] Складови разписки
  - [ ] Стоково-материални отчети
  - [ ] Протоколи за брак/липси/излишъци

- [ ] **Валутно отчитане**
  - [ ] Преоценка на валутни позиции
  - [ ] Отчитане на курсови разлики
  - [ ] Превалутиране на отчетност

### 2. ДДС отчитане (ЗДДС, ППЗДДС)

- [ ] **Документи и регистри**
  - [ ] Издаване на фактури и известия съгласно ЗДДС
  - [ ] Регистър на издадените фактури
  - [ ] Регистър на получените фактури
  - [ ] Дневник за покупки
  - [ ] Дневник за продажби

- [ ] **Декларации**
  - [ ] Справка-декларация по ЗДДС (обр. 025)
  - [ ] VIES декларация за ВОД
  - [ ] Дневници за покупки/продажби в XML формат
  - [ ] Протоколи за самоначисляване на ДДС

- [ ] **Специфични ДДС режими**
  - [ ] Режим "Касова отчетност"
  - [ ] Режим за стоки втора употреба
  - [ ] Режим за туристически услуги
  - [ ] Режим за доставки на инвестиционно злато
  - [ ] Режим за обратно начисляване
  - [ ] Режим за дистанционни продажби
  - [ ] Режими в рамките на Съюза/извън Съюза за електронни услуги (OSS/IOSS)

- [ ] **Други ДДС изисквания**
  - [ ] Корекции на ползван данъчен кредит
  - [ ] Годишни изравнявания
  - [ ] Проследяване на авансови плащания

### 3. Фискализация (Наредба Н-18)

- [ ] **Фискални устройства**
  - [ ] Интеграция с различни видове фискални устройства
  - [ ] Издаване на фискални бонове
  - [ ] Дневни Z-отчети
  - [ ] Периодични X-отчети

- [ ] **СУПТО изисквания**
  - [ ] Уникален номер на всяка продажба (УНП)
  - [ ] Непроменяемост на записите за продажби
  - [ ] Пълна история на операциите
  - [ ] Експорт на данни във формат, изискван от НАП
  - [ ] Съответствие с останалите изисквания на Приложение №29

- [ ] **Други изисквания**
  - [ ] Електронно предаване на данни към НАП
  - [ ] Отчети за наличности и обороти
  - [ ] Управление на фискални периоди
  - [ ] Връзка между фискален бон и продажба в системата

### 4. Корпоративно данъчно облагане (ЗКПО)

- [ ] **Формиране на данъчна основа**
  - [ ] Преобразуване на счетоводния финансов резултат
  - [ ] Отчитане на постоянни и временни данъчни разлики
  - [ ] Данъчни амортизации
  - [ ] Пренасяне на данъчни загуби

- [ ] **Деклариране и плащане**
  - [ ] Годишна данъчна декларация по чл.92 от ЗКПО
  - [ ] Авансови вноски за корпоративен данък
  - [ ] Деклариране на други корпоративни данъци
  - [ ] Данък при източника

- [ ] **Други корпоративни данъци**
  - [ ] Данък върху разходите
  - [ ] Данък върху дивидентите
  - [ ] Алтернативни данъци

### 5. Трудово и осигурително право (КТ, КСО, ЗДДФЛ)

- [ ] **Трудови правоотношения**
  - [ ] Трудови договори и допълнителни споразумения
  - [ ] Уведомления по чл. 62 и чл. 123 от КТ
  - [ ] Работно време и отработени часове
  - [ ] Отпуски (платен, неплатен, болничен)
  - [ ] Болнични и обезщетения

- [ ] **Заплати и възнаграждения**
  - [ ] Изчисляване на брутни и нетни заплати
  - [ ] Изчисляване на осигуровки (работодател и служител)
  - [ ] Удръжки от заплати (запори, лични осигуровки)
  - [ ] Ведомости за заплати
  - [ ] Фишове за заплата

- [ ] **Осигуровки и данъци**
  - [ ] Месечни декларации образец 1
  - [ ] Декларация образец 6
  - [ ] Данъци по ЗДДФЛ
  - [ ] Годишна декларация за доходите

- [ ] **Граждански договори и други възнаграждения**
  - [ ] Договори за извънтрудови правоотношения
  - [ ] Изчисляване на възнаграждения
  - [ ] Данъчно третиране
  - [ ] Осигурителен режим

### 6. Други специфични изисквания

- [ ] **Интрастат**
  - [ ] Месечна декларация за вътреобщностна търговия
  - [ ] Кодове по Комбинираната номенклатура
  - [ ] Статистическа стойност
  - [ ] Условия на доставка и транспорт

- [ ] **SAF-T (Standard Audit File for Tax)**
  - [ ] Генериране на SAF-T файл съгласно спецификацията
  - [ ] Експорт на мастър данни (контрагенти, стоки)
  - [ ] Експорт на счетоводни записи
  - [ ] Експорт на данни за продажби и покупки
  - [ ] Валидация на файла преди подаване

- [ ] **Електронно фактуриране**
  - [ ] Създаване на е-фактури в структуриран формат
  - [ ] Електронно подписване на фактури
  - [ ] Изпращане и получаване на е-фактури
  - [ ] Съхранение на е-фактури

- [ ] **GDPR и защита на данните**
  - [ ] Управление на лични данни
  - [ ] Политика за поверителност
  - [ ] Регистър на дейностите по обработка
  - [ ] Процедури за упражняване права на субектите на данни

- [ ] **Транслитерация и многоезичност**
  - [ ] Транслитерация на имена на партньори (физически и юридически лица)
  - [ ] Транслитерация на географски обекти (градове, села, улици)

  - [ ] Превод на стокови наименования и услуги

## Модули в l10n-bulgaria

### Основни модули

#### l10n_bg_config

**Описание:** Основен конфигурационен модул за българската локализация, който автоматично настройва Odoo за съответствие с българските счетоводни и законови стандарти.

**Функционалности:**
- Автоматично инсталиране на необходимите модули за българската локализация
- Настройки на компанията за български бизнес среди
- Предварително конфигурирани параметри за работа с българско законодателство
- Интеграция с други модули от българската локализация

#### l10n_bg

**Описание:** Основен модул за българската локализация, съдържащ базови настройки и функционалности.

**Функционалности:**
- Български език и преводи на интерфейса
- Основни настройки за българска среда
- Локализирани формати за дати, числа и валути
- Базова структура за сметкоплан съгласно българското законодателство

### Счетоводни модули

#### l10n_bg_account

**Описание:** Модул за счетоводство съгласно българските стандарти и изисквания.

**Функционалности:**
- Детайлен счетоводен сметкоплан съгласно Национални счетоводни стандарти
- Данъчни групи и ставки съобразно ЗДДС
- Автоматично създаване на счетоводни записи съобразно българското законодателство
- Справки и отчети за целите на финансовото отчитане
- Управление на финансовата година и счетоводни периоди

#### l10n_bg_account_bank_statement_import

**Описание:** Модул за импортиране на банкови извлечения от български банки.

**Функционалности:**
- Поддръжка на формати от основните български банки
- Автоматично сравняване и съпоставяне на транзакции
- Автоматично осчетоводяване на банкови транзакции
- Валидация на импортираните данни

#### l10n_bg_address_extended

**Описание:** Разширен модул за управление на български адреси и адресни формати.

**Функционалности:**
- Поддръжка на български адресен формат
- Компоненти на адреса съгласно българските стандарти
- Валидация на пощенски кодове
- Интеграция с ЕКАТТЕ (Единен класификатор на административно-териториалните и териториалните единици)

### Данъчно отчитане

#### l10n_bg_tax

**Описание:** Модул за данъчно отчитане съгласно българското законодателство.

**Функционалности:**
- Дефиниции на данъчни ставки и групи
- Автоматично изчисление на ДДС
- Обработка на различни данъчни режими (стандартен, касова отчетност и др.)
- Справки за данъчно отчитане

#### l10n_bg_vat_reports

**Описание:** Специализиран модул за генериране на справки и декларации по ДДС.

**Функционалности:**
- Дневници за покупки и продажби
- Справка-декларация по ДДС
- VIES декларация за вътреобщностни доставки
- XML експорт на декларации за НАП
- Валидация на данните преди подаване

#### l10n_bg_tax_bg_reports_audit

**Описание:** Модул за одит и контрол на данъчната отчетност.

**Функционалности:**
- Проверки за съответствие с данъчното законодателство
- Идентификация на потенциални грешки при данъчно отчитане
- Предварителна валидация на данни преди подаване към НАП
- Поддръжка на одит версии на подадени декларации

### Фискализация

#### l10n_bg_fiscalization

**Описание:** Модул за фискализация на продажби съгласно Наредба Н-18.

**Функционалности:**
- Интеграция с фискални устройства
- Управление на фискални бонове
- Съответствие със СУПТО изискванията
- Свързаност с НАП за електронно отчитане
- Управление на фискални устройства и касови апарати

#### l10n_bg_pos_fiscalization

**Описание:** Разширение на ПОС модула с функционалности за фискализация.

**Функционалности:**
- Интеграция между ПОС и фискални устройства
- Автоматично издаване на фискален бон при продажба
- Поддръжка на специфични операции (сторно, отстъпки, промоции)
- Фискални отчети и справки за ПОС операции

#### l10n_bg_erp_net_fp

**Описание:** Интеграция с фискални принтери чрез ErpNet.FP сървър.

**Функционалности:**
- Печат на фискални бонове в реално време
- Мониторинг на статуса на фискалните принтери
- Автоматично повторно отпечатване при грешка
- Поддръжка на множество фискални принтери
- Фонови актуализации на статуса на принтера
- Детайлно записване на грешки
- Поддръжка на различни модели принтери

### Специализирани модули

#### l10n_bg_intrastat

**Описание:** Модул за Интрастат отчетност при вътреобщностна търговия.

**Функционалности:**
- Автоматично събиране на данни за Интрастат декларацията
- Класификация на стоки по Комбинирана номенклатура
- Генериране на Интрастат декларация
- Експорт на данни за електронно подаване

#### l10n_bg_hr_payroll

**Описание:** Модул за управление на заплати съгласно българското трудово и осигурително законодателство.

**Функционалности:**
- Изчисляване на заплати съгласно КТ
- Автоматично определяне на осигурителни и данъчни задължения
- Генериране на фишове за заплата
- Ведомости за заплати
- Подготовка на декларации за НАП и НОИ

#### l10n_bg_hr_payroll_classifications

**Описание:** Модул за класификация на персонала съгласно националните стандарти.

**Функционалности:**
- Управление на НКПД (Национална класификация на професиите и длъжностите)
- Класификация по икономически дейности (КИД) с осигурителни прагове
- Йерархична структура на НКПД (професионални групи, категории)
- Интеграция с позициите на служителите
- Български специфични HR менюта и структура

#### l10n_bg_saft

**Описание:** Модул за генериране на SAF-T файл (Standard Audit File for Tax).

**Функционалности:**
- Генериране на SAF-T XML файл съгласно българските изисквания
- Проследяване на счетоводни данни за одит
- Валидация на SAF-T файл преди подаване
- Подготовка на данни за ревизии от НАП

#### l10n_bg_einvoicing

**Описание:** Модул за електронно фактуриране.

**Функционалности:**
- Създаване на електронни фактури в стандартизиран формат
- Електронно подписване на фактури
- Изпращане и получаване на е-фактури
- Съхранение на е-фактури според законовите изисквания

#### l10n_bg_city

**Описание:** Модул за управление на български населени места.

**Функционалности:**
- Пълна номенклатура на населените места в България
- Класификация на градове, села и общини
- Интеграция с ЕКАТТЕ (Единен класификатор на административно-териториалните и териториалните единици)
- Разширяване на стандартните функции за адресиране

#### l10n_bg_tax_offices

**Описание:** Модул за данъчни служби и офиси на НАП.

**Функционалности:**
- Добавяне на данъчни служби и отдели на НАП в партньорите
- Автоматично свързване на партньори с техните данъчни служби
- Данни за връзка с данъчните служби
- Териториално разпределение на офисите

#### l10n_bg_mrp_multilang

**Описание:** Многоезичност за производствените работни центрове.

**Функционалности:**
- Многоезични полета за имена на работни центрове
- Превод на операции в производствения процес
- Поддръжка на документи на различни езици

#### l10n_bg_report_stock

**Описание:** Документи за доставка и складови операции.

**Функционалности:**
- Приемо-предавателни протоколи за стокови доставки
- Складови разписки съгласно българските изисквания
- Модифицирани складови отчети за съответствие с местните изисквания

## Инструкции за инсталиране

За да инсталирате необходимите модули, използвайте стандартния процес за инсталиране на Odoo модули от OCA хранилища:

1. Добавете хранилището към вашия Odoo инстанс:
```
bash
git clone https://github.com/OCA/l10n-bulgaria.git
```
2. Добавете пътя към хранилището във вашия addons_path:
```

addons_path = /path/to/odoo/addons,/path/to/l10n-bulgaria
```
3. Рестартирайте Odoo сървъра и инсталирайте необходимите модули от интерфейса.

## OCA Bulgaria

[OCA Bulgaria](https://github.com/orgs/OCA-Bulgaria) е официалната българска локална общност в рамките на OCA (Odoo Community Association). Тази организация обединява българските разработчици и потребители на Odoo, които допринасят за развитието на българската локализация.

### Цели на OCA Bulgaria

- Създаване и поддръжка на качествени модули за българската локализация на Odoo
- Осигуряване на съответствие с постоянно променящото се българско законодателство
- Подпомагане на българските потребители и имплементатори на Odoo
- Споделяне на знания и опит в областта на ERP системите

### Членство и участие

Всички заинтересовани разработчици, счетоводители, консултанти и потребители са поканени да се присъединят към OCA Bulgaria и да допринесат за развитието на българската локализация на Odoo.

За повече информация и начини за участие, посетете [GitHub страницата на OCA Bulgaria](https://github.com/orgs/OCA-Bulgaria).
